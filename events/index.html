Connection settings

This reads your private fdr-event-calendar repository. Create a fine-grained GitHub token with access to that repository only and Contents: read-only.

Create a GitHub read token

The token is sent only to GitHub. “Remember” saves it in this widget’s local browser storage. It is never saved in your Grist document or the widget code. Use a read-only token, not your Ticketmaster key.

How updates work

GitHub collects Fishers Event Center, Ruoff, Riverview Health Arena at Innovation Mile, and AMP's Ticketmaster listings daily. This page fetches the AMP city calendar directly from your computer because the city does not accept GitHub server requests.

After your first verified sync, this page checks on opening and every 30 minutes while visible. It also checks when you return after 30 minutes. Grist must be running with this page visible.

The preview shows new and changed events. Sync matches Event_Key and Venue_Key, updates source fields, and keeps existing row IDs. Your Review_Note and any extra note, reference, or formula columns are preserved. Updated collector notes go into Source_Review_Note, which is added on the first sync.

Source_Checks stores the latest feed status and is added on the first direct AMP sync if needed. If AMP cannot load, its saved Grist events are retained while the other feeds update. Calendar and restaurant sales are not changed by this widget.
